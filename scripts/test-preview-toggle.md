# プレビュー切り替え機能のテスト手順

## 実装完了内容

1. **previewType state の追加**
   - `useState<"contract" | "invoice">("contract")` を追加
   - 初期値は契約書プレビュー

2. **切り替えボタンUI の実装**
   - 「契約書」と「送付状」の2つのボタン
   - アクティブなボタンは `variant="default"`
   - 非アクティブなボタンは `variant="outline"`
   - `flex-1` で両方のボタンが同じ幅

3. **iframe の動的変更**
   - `src={previewType === "contract" ? result.contractPdfUrl : result.invoicePdfUrl}`
   - タイトルも動的に変更

## 手動テスト手順

1. **サーバーが起動しているか確認**
   ```bash
   npm run dev
   ```

2. **ブラウザで開く**
   ```
   http://localhost:3000
   ```

3. **書類を生成**
   - 会社名: 「プレビューテスト株式会社」
   - 住所: 「東京都渋谷区渋谷1-1-1」
   - 代表者名: 「プレビュー 太郎」
   - 「書類を生成」ボタンをクリック

4. **プレビュー切り替えをテスト**
   - 初期表示: 契約書プレビューが表示される（「契約書」ボタンがアクティブ）
   - 「送付状」ボタンをクリック: 送付状PDFに切り替わる
   - 「契約書」ボタンをクリック: 契約書PDFに戻る
   - プレビューの高さ: 600px（スクロール可能）

## 確認ポイント

✓ 初期表示で契約書プレビューが表示される
✓ 「契約書」ボタンがアクティブ（青色背景）
✓ 「送付状」ボタンをクリックすると送付状PDFに切り替わる
✓ ボタンのアクティブ状態が切り替わる
✓ プレビューの高さが600pxで固定
✓ レスポンシブデザインが維持されている（モバイルでも見やすい）

## トラブルシューティング

### プレビューが表示されない
- サーバーが起動しているか確認
- 書類が正しく生成されているか確認（result が null でないか）

### ボタンが表示されない
- コンポーネントのインポートを確認（Button が正しくインポートされているか）
- Tailwind CSS のビルドを確認

### 切り替えが動作しない
- ブラウザのコンソールでエラーを確認
- previewType state が正しく設定されているか確認
