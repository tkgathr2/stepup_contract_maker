# Claude Codeへの実装指示

## 重要事項

**docs/plan.md を唯一の仕様として実装してください。**

## 実装手順

1. **docs/checkpoints.md の CP-01 から順番に進めてください**
   - CP-01: プロジェクト初期化と基本セットアップ
   - CP-02: データベースと認証のセットアップ
   - CP-03: ログシステムとテンプレート管理
   - CP-04: PDF生成機能（通常生成）
   - CP-05: 一括生成と履歴機能

2. **各チェックポイントの完了条件**
   - チェックポイント内のすべての項目が完了していること
   - エラーなく動作すること
   - 次のチェックポイントに進める状態であること

3. **エラー発生時の対応**
   - 失敗したら直前のチェックポイントに戻る
   - 同じチェックポイントを再実行する
   - **logs/debug_latest.txt に原因が分かる形で記録する**
   - エラーログには必ずユーザー情報（userId, email, name）を含める

4. **不明点がある場合**
   - 推測で決めない
   - **必ずユーザーに確認する**

## 実装時の注意事項

### ログ記録
- すべてのログにユーザー情報を含める
- フォーマット: `[YYYY-MM-DD HH:mm:ss] [USER: userId/email/name] [ACTION: 処理名] メッセージ`
- エラー時は詳細なスタックトレースも記録

### バリデーション
- 会社名: 最大100文字
- 住所: 最大500文字
- 代表者名: 最大100文字

### 一括生成の出力
- ZIPファイルではなく、個別のPDFファイルとして出力
- 各PDFのダウンロードリンクを一覧表示

### セキュリティ
- すべてのAPI Routeで認証チェックを実施
- ユーザーごとのデータ分離（自分の履歴のみ閲覧可能）
- ファイルパストラバーサル対策

## 技術スタック

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- shadcn/ui
- NextAuth.js (Google OAuth)
- Prisma
- docxtemplater
